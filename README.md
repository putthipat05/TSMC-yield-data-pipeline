# TSMC-yield-data-pipeline

## Business task

- Build an automated data pipeline to clean noisy fab logs, integrate relational yield data, and deliver structured pivot reports that help process engineers pinpoint defect patterns and optimize wafer yield.

## Data Acknowledgement 

- The dataset used in this project is a custom-generated synthetic dataset (1,000 records) designed to simulate real-world data pipeline challenges in semiconductor fabrication (e.g., TSMC/ASML wafer test environments).
- Privacy & Confidentiality: No proprietary or real manufacturing data was used, ensuring full compliance with industry confidentiality while maintaining high domain relevance.

## Tool

- Programmatically generated using Python (NumPy & Pandas)
